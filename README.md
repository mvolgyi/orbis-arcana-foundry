# Orbis Arcana para Foundry VTT

Sistema de juego **Orbis Arcana** para Foundry VTT v14: d20 con cuatro grados de éxito, tres acciones por turno, ritmos de competencia y el mundo de Valtera. Este repositorio solo publica las versiones instalables; el desarrollo es privado.

*The **Orbis Arcana** game system for Foundry VTT v14. This repository only hosts the installable releases.*

## Instalar / Install

En Foundry: **Game Systems → Install System**, y pegar en **Manifest URL** / paste into **Manifest URL**:

```
https://github.com/mvolgyi/orbis-arcana-foundry/releases/latest/download/system.json
```

Requiere Foundry VTT 14 (14.363 o posterior). / Requires Foundry VTT 14 (14.363 or later).

## Qué trae / What's included

- Asistente del Despertar para crear personajes y subir de nivel. / Awakening wizard for character creation and leveling up.
- Compendios en español y en inglés: conjuros, dotes, rasgos de clase, clases, pueblos, orígenes, equipo, personajes pregenerados y el Libro del jugador. / Compendiums in Spanish and English: spells, feats, class features, classes, ancestries, backgrounds, equipment, pregenerated characters and the Player's Book.
